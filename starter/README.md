`/.well-known/x402`. Each file is assembled from that host's own catalogue
entries — resource URLs, descriptions and declared version. Nothing is
invented and no host was contacted to build these.

Find your hostname, drop the JSON at `/.well-known/x402`, then publish the
TXT record printed alongside it. Read the notes first — `name` is a
placeholder and `kind` is an inference from the fact that you list resources.
